# Canopi 2.1 decision ledger

Status: the user's decisions for Canopi 2.1 (epic canopi-f47t.52), from 2026-10-16. Rows are appended when a decision is taken; a row's id, date, decision and words are never rewritten, and only its supersedes and implemented-by columns gain text; a superseded or withdrawn row stays and names its successor.

`Q` rows are the user's. Engineering decisions taken under the user's mandate of 2026-10-17 carry an `E` or `M` id, so the user can overturn them; an `E` or `M` row never authorises a ratchet exception, a raised baseline or a change to a user-reviewed data file (ctr §12). Each row names the ADR rule, plan item (`plan`) or contract (`ctr`, the contracts file) that implements it; when the plan is deleted, its items live in code and tests.
