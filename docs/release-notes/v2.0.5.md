# Canopi 2.0.5

A Canopi Desktop fix that brings back Data library rasters an earlier version stopped showing. The Web Edition has no changes.

## Canopi Desktop

### Data library

- If a failed update of the Data library under Canopi 2.0.3 (or 2.0.4 before this fix) left it empty, the rasters whose saved record survived were still on this device but no longer listed. At its first launch, Canopi 2.0.5 lists them again. Each comes back as an import to prepare again: click Retry beside it. The results calculated from it come back too, to calculate again once Retry has prepared it.
- Canopi lists a raster again only when a record saved beside its files says which item it belongs to and matches them. A file no record names, such as one from an import you cancelled, stays on this device and unlisted.

## Known limits

The known limits of [Canopi 2.0.4](https://github.com/opencanopi/canopi/releases/tag/v2.0.4) still apply.

## Before you upgrade

Canopi 2.0.4 updates itself to 2.0.5 on Windows and Linux; on macOS, download it from projectcanopi.com. Installing 2.0.5 over 2.0.x keeps your Designs, Drafts, Data library and settings, and they still open in 2.0.4. On Linux, Canopi needs Ubuntu 22.04, Debian 12 or a newer distribution. On a Mac, Canopi needs macOS 12 or later with Safari 16.4 or later (Software Update offers it). The Web Edition runs in Safari 16.4, Chrome 111, Edge 111 or Firefox 121 or later.

The installers carry no publisher certificate, so the first open takes one more step. On macOS, open the dmg and drag Canopi to Applications, then open Canopi. If macOS says it cannot verify Canopi or check it for malware, click Done, Cancel or OK (not Move to Trash), open System Settings › Privacy & Security (on macOS 12, System Preferences › Security & Privacy), click Open Anyway beside Canopi and confirm. If macOS says Canopi is damaged, open Terminal, run `xattr -dr com.apple.quarantine /Applications/Canopi.app`, then open Canopi. On Windows, if SmartScreen appears, click More info › Run anyway.
