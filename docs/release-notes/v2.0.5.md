# Canopi 2.0.5

A Canopi Desktop fix that brings back Data library rasters an earlier version stopped showing. The Web Edition has no changes.

## Canopi Desktop

### Data library

- If a failed update of the Data library under Canopi 2.0.3 (or 2.0.4 before this fix) left it empty, your imported rasters were still on this device but no longer listed. At its first launch, Canopi 2.0.5 lists them again, with the results calculated from them. Each comes back as an import to prepare again: click Retry beside it.
- Canopi lists a raster again only when the file saved beside it says which item it belongs to and matches it. A file without that record, such as one from an import you cancelled, stays on this device and unlisted.

## Known limits

The known limits of [Canopi 2.0.4](https://github.com/opencanopi/canopi/releases/tag/v2.0.4) still apply.

## Before you upgrade

Canopi 2.0.4 updates itself to 2.0.5 on Windows and Linux; on macOS, download it from projectcanopi.com. Installing 2.0.5 over 2.0.x keeps your Designs, Drafts, Data library and settings, and they still open in 2.0.4. The installers carry no publisher certificate; the first-open steps in the [Canopi 2.0.4 notes](https://github.com/opencanopi/canopi/releases/tag/v2.0.4) still apply.

## Source code

Canopi is AGPL-3.0-or-later free software; its installers include the GeoLibre tool, which contains the AGPL-3.0-or-later `wbspatialstats` tools.
