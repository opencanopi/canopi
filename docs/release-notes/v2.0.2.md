# Canopi 2.0.2

A fix and security update to Canopi 2.0 for Desktop and the Web Edition.

## Fixed

- A site data raster keeps drawing after you change its colour ramp or range: switching a layer from Terrain to Relief, then back, or hiding and showing it, no longer leaves the map blank until a restart.
- Hiding the Plants layer hides the selected plant's name label too, and the label follows the layer's opacity.
- Closing Canopi when your settings can't be saved now says so. Your Design is saved first; then you choose Retry, Close anyway (losing the latest settings changes) or Cancel to keep working.
- A group holding a locked plant, zone or note can be clicked and selected again. Moving it is still refused, and a short message says why: "Locked: unlock to move". Unlock on the group unlocks the group and its members in one step, undone by one Undo.
- On the Web Edition, Edit › Save as stamp and its command palette entry are greyed out instead of doing nothing: saving stamps is a Desktop feature for now.
- On Desktop, a link such as a map credit opens in your browser (or your mail app for an email address) instead of replacing Canopi's window with the web page.
- The Linux packages now start on Ubuntu 22.04 and Debian 12: earlier .deb and AppImage packages needed a newer system library (glibc 2.39) than those distributions have.

## Security

Canopi Desktop moves to Tauri 2.12.4 with its dialog, single-instance and opener plugins, closing the Tauri advisories [GHSA-7gmj-67g7-phm9](https://github.com/advisories/GHSA-7gmj-67g7-phm9) (CVE-2026-42184) and [GHSA-w28w-mhc8-qvjv](https://github.com/advisories/GHSA-w28w-mhc8-qvjv), in the asynchronous asset protocol handler Canopi uses to read your site data files and cached plant images, which serves only those folders. The app window now only ever shows Canopi itself: web links, email links and any other address open outside it or not at all.

## Before you upgrade

Installing 2.0.2 over 2.0.0 or 2.0.1 keeps your Designs, Drafts, Data library and settings.

Linux: Canopi needs Ubuntu 22.04, Debian 12 or a newer distribution.

The installers are not signed yet. On macOS (12 or later), open Canopi once, then go to System Settings › Privacy & Security › Open Anyway; if macOS says the app is damaged, run `xattr -dr com.apple.quarantine /Applications/Canopi.app` in Terminal. On Windows, if SmartScreen appears, click More info › Run anyway.

The known limits of [Canopi 2.0.0](https://github.com/opencanopi/canopi/releases/tag/v2.0.0) still apply.

## Source code

Canopi is AGPL-3.0-or-later free software; its installers include the GeoLibre tool, which contains the AGPL-3.0-or-later `wbspatialstats` tools. The complete source of this release is Canopi at tag `v2.0.2` plus the `geolibre-rust` and `whitebox-wasm` revisions in `desktop/THIRD_PARTY_NOTICES.md`, linked from the release page.
