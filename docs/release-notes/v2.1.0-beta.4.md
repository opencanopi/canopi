# Canopi 2.1.0 beta 4

The fourth beta of Canopi 2.1, for Canopi Desktop on Windows, Linux and macOS. It carries the Phase 2 architecture and interface foundations built on top of beta 3.

## Units and measurements

- Metric and US customary units now apply consistently across the canvas, scale bar, species dimensions, measurements, LiDAR elevation readouts and PDF export.
- Quantity fields format and parse localized unit suffixes cleanly across all 11 languages.

## Workspace and tools

- Keyboard shortcuts and context menus share one command table across the canvas and panels.
- The title bar adapts cleanly across narrow and wide windows, with unified icon buttons and file actions.
- Color selection and inline renaming share consistent controls and keyboard behaviour across Design objects and the Data library.
- Species sorting and favorites search follow the displayed species name consistently.

## Stability and platform polish

- Tighter boundaries between Design editing, canvas runtime state and platform services make save, undo and file-open flows more predictable.
- File-delivery and shell failure notices surface clear recovery guidance instead of failing silently.

## Known limits

- On Linux, if your file manager cannot select a file (it offers no `org.freedesktop.FileManager1`), Show in folder, and a new problem report, open the folder without selecting the file.
- On GNOME with Wayland, opening a second file while Canopi runs may show "Canopi is ready" instead of raising its window: GNOME refuses to bring the window forward. Click the notification or switch to Canopi.

## Before you install

If you run 2.1.0 beta 1, beta 2 or beta 3, Canopi updates itself to this beta on Windows and Linux: wait for the notice at launch, or choose Help › About Canopi › Check for updates. On macOS, About links to projectcanopi.com to download it.

Canopi 2.0.x updates itself on the stable channel only: to try this beta from 2.0.x, install it by hand once. It keeps your Designs, Drafts, Data library and settings, and a Design saved by the beta still opens in Canopi 2.0. On Windows the beta comes as the setup `.exe` only; if you installed 2.0.x with the MSI, uninstall it first. The Windows installer uses your Windows display language when it is one of Canopi's 11 languages, and English otherwise. On Linux, Canopi needs Ubuntu 22.04, Debian 12 or a newer distribution. On a Mac, Canopi needs macOS 12 or later with Safari 16.4 or later (Software Update offers it).

The installers carry no publisher certificate, so the first open takes one more step. On macOS, open the dmg and drag Canopi to Applications, then open Canopi. If macOS says it cannot verify Canopi or check it for malware, click Done, Cancel or OK (not Move to Trash), open System Settings › Privacy & Security (on macOS 12, System Preferences › Security & Privacy), click Open Anyway beside Canopi and confirm. If macOS says Canopi is damaged, open Terminal, run `xattr -dr com.apple.quarantine /Applications/Canopi.app`, then open Canopi. On Windows, if SmartScreen appears, click More info › Run anyway.

## Source code

Canopi is AGPL-3.0-or-later free software; its installers include the GeoLibre tool, which contains the AGPL-3.0-or-later `wbspatialstats` tools. The complete source of this release is Canopi at tag `v2.1.0-beta.4` plus the `geolibre-rust` and `whitebox-wasm` revisions in `THIRD_PARTY_NOTICES.md`, linked from the release page.
