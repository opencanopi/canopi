# Canopi 2.0.3

A Web Edition update that keeps your Drafts safer in the browser and keeps open tabs working when a new version is published. Canopi Desktop has no new features; it gets one small fix it shares with the Web Edition.

## Web Edition

### Your Drafts and the browser's storage

Browsers may clear a site's saved data when space runs low. The Web Edition now asks your browser to keep your Drafts, and tells you when it might not.

- The first time you create or open a Design, a short line on the welcome screen says why Canopi asks this browser to keep your Drafts; then New or Open asks it once. Firefox asks you; Chrome, Edge and Safari decide on their own, often from how much you use the site, and may say no without asking.
- If the browser says no, or cannot keep them, the welcome screen and the save status warn that your Drafts may be cleared by this browser, and offer Download a copy.
- If you already have Drafts the browser is not keeping, the save status says so at launch. Click it (on a phone: Menu › File › Keep my drafts…) to read why, then choose Keep my drafts or Download a copy. The welcome screen offers the same.
- Each Draft on the welcome screen has Download a copy in its menu, so you can save any of them as a `.canopi` file.

### New versions while you work

- A tab left open while a new version is published keeps working: it can still open the PDF export, search the plant catalog and save, because each release keeps the previous release's files.
- When a tab notices that another version has been published, it shows one "New version" notice with a Reload button. You can dismiss it. Reload saves your Design first and reopens it; if the save fails, you can retry (unless another tab changed the Design), download a copy, reload without saving or cancel, and Cancel puts keyboard focus back on Reload.
- Tabs opened before 2.0.3 show no notice; reload them when convenient.

### Plant catalog

- Searching the plant catalog loads only the parts of its files the search needs, instead of whole files.

## Canopi Desktop and Web Edition

- The "Couldn't save" Details popover closes when focus leaves it or when a save problem dialog opens, and stays inside a narrow window.

## Before you upgrade

Nothing to do. On the Web Edition, open tabs from 2.0.2 keep working. Installing Canopi Desktop 2.0.3 over 2.0.0, 2.0.1 or 2.0.2 keeps your Designs, Drafts, Data library and settings. On Linux, Canopi needs Ubuntu 22.04, Debian 12 or a newer distribution.

The installers are not signed yet. On macOS (12 or later), open Canopi once, then go to System Settings › Privacy & Security › Open Anyway; if macOS says the app is damaged, run `xattr -dr com.apple.quarantine /Applications/Canopi.app` in Terminal. On Windows, if SmartScreen appears, click More info › Run anyway.

The known limits of [Canopi 2.0.0](https://github.com/opencanopi/canopi/releases/tag/v2.0.0) still apply.

## Source code

The complete source of this release is Canopi at tag `v2.0.3` plus the `geolibre-rust` and `whitebox-wasm` revisions in `desktop/THIRD_PARTY_NOTICES.md`, linked from the release page.
