# Canopi 2.0.3

A Web Edition update that keeps your Drafts safer in the browser and keeps open tabs working when a new version is published. Canopi Desktop has no change: its 2.0.3 installers work exactly like 2.0.2's.

## Web Edition

### Your Drafts and the browser's storage

Browsers may clear a site's saved data when space runs low. The Web Edition now asks your browser to keep your Drafts, and tells you when it might not.

- The first time you create or open a Design, a short line on the welcome screen says why Canopi asks this browser to keep your Drafts; then New or Open asks it once. Some browsers decide on their own without showing a prompt.
- If the browser says no, or cannot keep them, the welcome screen and the save status warn that your Drafts may be cleared by this browser, and point to Download a copy.
- If you already have Drafts the browser is not keeping, the save status says so at launch. Click it (on a phone: File › Keep my drafts…) to read why, then choose Keep my drafts or Download a copy.
- Each Draft on the welcome screen has Download a copy in its menu, so you can save any of them as a `.canopi` file.

### New versions while you work

- A tab left open while a new version is published keeps working: it can still open the PDF export, search the plant catalog and save, because each release keeps the previous release's files.
- When a tab notices that another version has been published, it shows one New version: Reload notice. You can dismiss it. Reload saves your Design first and reopens it; if the save fails, you can retry, download a copy, reload without saving or cancel.
- The plant catalog loads only the parts of its files a search needs, instead of whole files.

## Before you upgrade

Nothing to do. On the Web Edition, open tabs from 2.0.2 keep working; reload when convenient. Desktop users can stay on 2.0.2 or install 2.0.3, which works the same; installing it over 2.0.0, 2.0.1 or 2.0.2 keeps your Designs, Drafts, Data library and settings.

The installers are not signed yet. On macOS (12 or later), open Canopi once, then go to System Settings › Privacy & Security › Open Anyway; if macOS says the app is damaged, run `xattr -dr com.apple.quarantine /Applications/Canopi.app` in Terminal. On Windows, if SmartScreen appears, click More info › Run anyway.

The known limits of [Canopi 2.0.0](https://github.com/opencanopi/canopi/releases/tag/v2.0.0) still apply.

## Source code

Canopi is AGPL-3.0-or-later free software; its installers include the GeoLibre tool, which contains the AGPL-3.0-or-later `wbspatialstats` tools. The complete source of this release is Canopi at tag `v2.0.3` plus the `geolibre-rust` and `whitebox-wasm` revisions in `desktop/THIRD_PARTY_NOTICES.md`, linked from the release page.
