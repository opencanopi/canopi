# Canopi 2.1.0 beta 3

The third beta of Canopi 2.1, for Canopi Desktop on Windows, Linux and macOS. It carries Canopi 2.0.4, the stable release published the same day: what changed since beta 2 is below. The Web Edition gets these changes in 2.0.4.

## Ready for Canopi 2.1

If you try a later Canopi 2.1 beta and come back to this version, it shows what the newer version saved and changes none of it:

- A Design saved by a newer Canopi opens read-only. The save status shows "Read-only"; click it to read why and to choose Update, which opens About, where you can check for updates. Close is the only action: no editing, saving, printing or export. Recent Designs and the Draft list label it "Read-only: saved by a newer Canopi", and a Draft this version can't read says so instead.
- Your favorites, saved stamps and recent Designs, your settings and the Data library each show a notice when a newer Canopi saved them. You can view them, but changes aren't saved; changed settings apply until you close Canopi.
- Once a newer Canopi has opened your Data library, its items are listed by name and type with a note to update Canopi, and none is drawn on the map until you do; that includes items you imported before. Nothing is lost. Saved stamps from a newer Canopi are listed with a note to update Canopi and can't be placed, renamed, reordered or deleted.

## Data library

- If Canopi can't rebuild the Data library's list from your imported files (for example, a file it can't read), it no longer starts with an empty library and then deletes imported files at the next start. It keeps the old list, shows the Data library as unavailable and tries again at each start. If the list is missing, Canopi rebuilds it from your imported files.
- If Canopi can't read the Data library's list for a moment (for example, it is locked or on a network drive that fails a read), it shows the Data library as unavailable and changes nothing, instead of setting the list aside and rebuilding it.

## Updates

- Cancel in About now always stops an update check or download, even one that was just finishing; a cancelled download is never kept.
- In Settings › About, the Check for updates at launch switch no longer appears late and moves About Canopi… just as you click it.

## On a Mac

- The Mac app is now signed ad hoc (still without a publisher certificate), so on its first open macOS says it cannot verify Canopi or check it for malware, and System Settings offers Open Anyway, instead of saying the app is damaged (see Before you install).
- If your Mac is too old to run Canopi, the window says "Canopi couldn't start" and asks you to update the operating system, instead of staying empty. Canopi needs macOS 12 or later with Safari 16.4 or later; macOS 12 users get the newer Safari from Software Update.

## Moving around the canvas

- On a Mac, a new installation of Canopi starts with the pointing device set to Trackpad: two fingers pan, pinch zooms. With a mouse, switch it in Settings › Canvas › Pointing device. Settings you already have are kept.
- The Select tool's hint names Settings › Canvas › Pointing device, and on a Mac it says Option-click removes from the selection.
- The welcome screen has a "Moving around" link that opens Help at its gestures section. On a Mac, Help's gestures name two fingers on the trackpad or the Pan tool for panning, Option-click for removing, and the trackpad twist for turning the view.
- Settings › Files and data says your favorites stay on this computer, not in a Design.

## Known limits

- On Linux, if your file manager cannot select a file (it offers no `org.freedesktop.FileManager1`), Show in folder, and a new problem report, open the folder without selecting the file.
- On GNOME with Wayland, opening a second file while Canopi runs may show "Canopi is ready" instead of raising its window: GNOME refuses to bring the window forward. Click the notification or switch to Canopi.

## Before you install

If you run 2.1.0 beta 1 or beta 2, Canopi updates itself to this beta on Windows and Linux: wait for the notice at launch, or choose Help › About Canopi › Check for updates. On macOS, About links to projectcanopi.com to download it.

Canopi 2.0.4 updates itself on the stable channel only: to try this beta from 2.0.x, install it by hand once. It keeps your Designs, Drafts, Data library and settings, and a Design saved by the beta still opens in Canopi 2.0. On Windows the beta comes as the setup `.exe` only; if you installed 2.0.x with the MSI, uninstall it first. The Windows installer uses your Windows display language when it is one of Canopi's 11 languages, and English otherwise. On Linux, Canopi needs Ubuntu 22.04, Debian 12 or a newer distribution. On a Mac, Canopi needs macOS 12 or later with Safari 16.4 or later (Software Update offers it).

The installers carry no publisher certificate, so the first open takes one more step. On macOS, open the dmg and drag Canopi to Applications, then open Canopi. If macOS says it cannot verify Canopi or check it for malware, click Done, Cancel or OK (not Move to Trash), open System Settings › Privacy & Security (on macOS 12, System Preferences › Security & Privacy), click Open Anyway beside Canopi and confirm. If macOS says Canopi is damaged, open Terminal, run `xattr -dr com.apple.quarantine /Applications/Canopi.app`, then open Canopi. On Windows, if SmartScreen appears, click More info › Run anyway.

## Source code

Canopi is AGPL-3.0-or-later free software; its installers include the GeoLibre tool, which contains the AGPL-3.0-or-later `wbspatialstats` tools. The complete source of this release is Canopi at tag `v2.1.0-beta.3` plus the `geolibre-rust` and `whitebox-wasm` revisions in `THIRD_PARTY_NOTICES.md`, linked from the release page.
