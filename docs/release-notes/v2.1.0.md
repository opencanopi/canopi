# Canopi 2.1.0

Draft: lines are added as Phase 0 and later steps merge; the release rewrites them into the final notes.

## Canopi Desktop

### Updates

- Canopi for Desktop now updates itself. It checks once at launch (turn this off in Settings › About › Check for updates at launch) and from Help › About Canopi › Check for updates; a new version shows a notice that opens About, where Download and install starts it.
- About offers Cancel during an update download, and Retry when a download fails.
- On Linux the `.deb` asks for your password to install; if the update cannot replace itself, About links to projectcanopi.com. A Linux install that fails keeps your Design open and says why.
- On Windows the installer closes Canopi after your Design is saved; if it fails, Canopi says Update not installed at the next launch.
- Betas update themselves to each new beta from the beta channel.

### Opening Designs

- Double-clicking a `.canopi` file opens it in Canopi on Windows and with the `.deb`.

### Problem reports

- Problem reports name the webview version.

## Known limitations

- On GNOME with Wayland, opening a second file while Canopi runs may show "Canopi is ready" instead of raising its window: GNOME refuses to bring the window forward. Click the notification or switch to Canopi.
