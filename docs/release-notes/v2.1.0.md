# Canopi 2.1.0

Draft: lines are added as Phase 0 and later steps merge; the release rewrites them into the final notes.

## Canopi Desktop

### Updates

- On Windows and Linux, Canopi Desktop now updates itself. It checks once at launch (turn this off in Settings › About › Check for updates at launch), or when you choose Help › About Canopi › Check for updates. When a new version is out, a notice opens About, which shows the version and a What's new link; Download and install starts the update. On macOS, About links to projectcanopi.com to download the new version.
- About offers Cancel while an update downloads, and Retry if the download fails. A download that can't be verified offers Check for updates instead.
- On Linux, the AppImage updates in place and the `.deb` asks for your password. If Canopi can't install the update (no password prompt on the system, or the AppImage's folder can't be changed), About links to projectcanopi.com instead. If an install fails, your Design stays open and Canopi says why ("Update not installed: …"); otherwise Canopi saves and restarts into your Design.
- On Windows, Canopi saves your Design, closes while the installer runs and reopens the Design afterwards. If the update doesn't install, Canopi says "Update not installed" at the next launch.
- If you close Canopi while an update installs or finishes, the window says "Installing update…" or "Finishing update…" and closes once the update is done.
- A beta updates itself to each newer beta and to the stable release after it. To leave the betas, install a stable build.

### Opening Designs

- Double-clicking a `.canopi` file opens it in Canopi on Windows and on Linux with the `.deb`. With the AppImage or on macOS, open Designs from Canopi.
- Opening a `.canopi` file while Canopi is running opens it in the window you have, after asking about unsaved changes. If you open several at once, Canopi opens the first and says "Canopi opens one Design at a time".
- Show in folder, on a Recent Design or a problem report, opens its folder with the file selected.

### Problem reports

- Problem reports name the webview version.

### Fixes

- Importing several elevation tiles that share one grid no longer drops a row of cells at the item's edge.

## Web Edition

- About has an Open-source notices link listing the licences of the software Canopi includes.
- The map recovers cleanly after the browser loses its graphics context.
- In Russian, the elevation profile's Copy values no longer wraps on phones.

## Security

- Canopi Desktop updates tokio to 1.54.1 (RUSTSEC-2026-0386).

## Known limits

- On GNOME with Wayland, opening a second file while Canopi runs may show "Canopi is ready" instead of raising its window: GNOME refuses to bring the window forward. Click the notification or switch to Canopi.

## Before you upgrade

Canopi 2.0 does not update itself: install Canopi Desktop 2.1.0 by hand once, and later versions update themselves on Windows and Linux. Installing 2.1.0 over 2.0.x keeps your Designs, Drafts, Data library and settings; on Windows the MSI installs over 2.0.3. The Windows installer uses your Windows display language when it is one of Canopi's 11 languages, and English otherwise. On Linux, Canopi needs Ubuntu 22.04, Debian 12 or a newer distribution.

The installers are not signed yet. On macOS (12 or later), open Canopi once, then go to System Settings › Privacy & Security › Open Anyway; if macOS says the app is damaged, run `xattr -dr com.apple.quarantine /Applications/Canopi.app` in Terminal. On Windows, if SmartScreen appears, click More info › Run anyway.

## Source code

Canopi is AGPL-3.0-or-later free software; its installers include the GeoLibre tool, which contains the AGPL-3.0-or-later `wbspatialstats` tools. The complete source of this release is Canopi at tag `v2.1.0` plus the `geolibre-rust` and `whitebox-wasm` revisions in `desktop/THIRD_PARTY_NOTICES.md`, linked from the release page.
